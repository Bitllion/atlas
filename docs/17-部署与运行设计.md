# 部署与运行设计

## 1. 第一阶段部署

使用 Docker Compose 运行：

- PostgreSQL
- Backend
- Frontend

开发环境应提供明确的启动、停止、迁移和测试命令。

## 2. 配置管理

- 数据库连接、密钥和外部服务地址使用环境变量或安全配置。
- 不将密码、Token 和客户敏感信息提交到 Git。
- 开发、测试和生产配置分离。

## 3. 数据库迁移

- 所有结构变更通过 Alembic migration 管理。
- 迁移应可重复验证，并提供回滚策略。
- 生产环境不得依赖手工改表。

## 4. 可观测性

至少记录：

- 应用启动和停止
- 数据库连接状态
- API 错误
- Agent 采集状态
- Workflow 失败
- 通知发送状态

## 5. 运行边界

部署系统不得默认能够访问客户设备。设备访问和自动化执行必须经过网络、权限、Management Scope 和客户授权判断。

## 6. 发布验收

发布前确认：

- 数据库迁移成功
- 核心 API 可用
- 关键测试通过
- 配置不含敏感信息
- 文档与实现同步
