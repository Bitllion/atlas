# 技术架构设计

## 1. 总体原则

Atlas 采用简单、模块化、可演进的架构。优先保证核心模型稳定，避免不必要的微服务拆分。

## 2. 技术栈

- 后端：Python 3.12、FastAPI、SQLAlchemy、Alembic
- 数据库：PostgreSQL
- 前端：Vue 3、TypeScript
- Agent：Go
- 部署：Docker Compose

## 3. 后端模块

```text
backend/app/
├── main.py
├── config/
├── database/
├── models/
├── schemas/
├── api/
├── services/
└── core/
```

模型、服务和 API 应分层，避免在路由中堆积业务逻辑。

## 4. Agent 边界

Agent 负责硬件采集、长时间运行任务和后续自动化执行。Agent 不应绕过平台权限直接修改核心业务数据，采集结果必须标注来源并经过统一服务处理。

## 5. 部署原则

第一阶段使用 Docker Compose 运行 PostgreSQL、Backend 和 Frontend。部署配置应可重复执行，敏感配置通过环境变量或安全配置注入。
