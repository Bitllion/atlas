# 资产管理模型

## 1. 目标

管理基础设施资产从采购到退役的全生命周期，并与 Infrastructure Object 保持清晰分离。

## 2. Asset Record

Asset Record 表示管理信息，包括：

- 资产编号
- 采购申请与审批
- 供应商
- 合同
- 到货与验收
- 维保期限
- 所有权
- 使用方
- 部署位置
- 管理范围

Asset Record 可以关联一个或多个 Object，但不能取代 Object。

## 3. 生命周期

```text
申请 → 审批 → 采购 → 到货 → 验收 → 入库
→ 部署 → 使用 → 维保 → 调拨/更换 → 退役/报废
```

每个阶段应有明确状态、责任人、时间和审计记录。

## 4. 客户交付场景

资产可能属于企业、部署在客户数据中心、由客户使用、由企业负责硬件维保。模型必须分开表达：

- Ownership
- Usage
- Location
- Maintenance Responsibility
- Management Scope

## 5. 业务约束

- 资产编号不可替代设备序列号。
- 部件更换应更新 Object 关系并保留旧部件历史。
- 资产移动必须记录原位置和新位置。
- 维保记录必须关联资产和基础设施对象。
- 跨客户访问必须经过租户和权限校验。
