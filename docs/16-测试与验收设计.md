# 测试与验收设计

## 1. 测试目标

验证 Atlas Core 的模型完整性、业务边界和第一阶段可运行性。

## 2. 核心测试

- ObjectType 可创建和查询。
- Object 可创建、查询和更新。
- Specification 支持 JSON 扩展属性。
- Relationship 可创建、查询和失效。
- Object History 能记录 before/after 数据。
- 无权限用户不能访问受限租户、客户或站点。
- 采集失败不会删除已有对象和历史。

## 3. API 验收

```text
POST /api/v1/objects
GET /api/v1/objects
GET /api/v1/objects/{id}
PUT /api/v1/objects/{id}
POST /api/v1/relationships
GET /api/v1/relationships
```

## 4. 运行验收

- Backend 可以启动。
- `/docs` 可以访问 Swagger API。
- PostgreSQL 可以查询核心表。
- Frontend 可以查看对象列表和详情。
- Docker Compose 可以重复启动开发环境。

## 5. 回归要求

每次修改核心模型、迁移、API 或权限逻辑后，必须运行相关测试并记录结果。
