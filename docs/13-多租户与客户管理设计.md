# 多租户与客户管理设计

## 1. 目标

支持企业管理自有资产、客户资产和第三方托管环境中的基础设施，并保证组织和客户之间的数据隔离。

## 2. 核心维度

- Tenant：租户边界
- Organization：企业或组织
- Customer：客户
- Site：数据中心、机房或托管地点
- Ownership：所有权
- Usage：使用方
- Management Scope：管理范围

## 3. 典型场景

```text
资产所有者：企业
使用方：客户 A
部署地点：客户数据中心 B
维护责任：企业
带内权限：客户 A
硬件维保权限：企业
```

上述信息不能合并为单一 Owner 字段。

## 4. 隔离要求

- 默认按租户和客户隔离数据。
- 用户只能访问授权组织、站点和对象。
- 跨客户查询必须有明确权限和审计记录。
- 客户反馈和文档数据必须标注所属客户和来源。
- 站点变化和资产交付必须进入历史。
