# 工作流与权限设计

## 1. 目标

提供跨资产、运维、交付和维保流程的通用平台能力，同时隔离业务主数据与流程状态。

## 2. Workflow Engine

Workflow 负责：

- 审批
- 状态流转
- 流程编排
- 任务分派
- 超时和异常处理

Workflow 不直接替代 Asset、Object 或 Operations 数据模型。

## 3. 权限模型

权限至少考虑：

- 用户
- 角色
- 组织
- 客户/租户
- 站点
- 对象范围
- 操作范围

## 4. 管理范围

Management Scope 用于表达设备可以被如何管理，例如：

- `FULL_CONTROL`
- `MAINTENANCE_ONLY`
- `READ_ONLY`
- `NO_DIRECT_ACCESS`

系统不得因资产属于企业就默认拥有 OS、网络或应用权限。

## 5. 典型流程

采购、验收、维修、部件更换和客户交付均通过 Workflow 编排，但业务结果必须写入对应领域模型并保留审计记录。
