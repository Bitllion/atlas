# 前端设计

## 1. 目标

为业务用户提供对象、资产、运维和知识的统一工作界面，不暴露不必要的底层复杂实现。

## 2. 第一阶段页面

### Object Explorer

列表至少展示：

- Name
- Type
- Status
- Manufacturer

详情至少展示：

- Basic Info
- Specification
- Relationship
- History

## 3. 页面原则

- 页面围绕业务任务和对象上下文组织。
- 对象详情应能进入资产、工单、关系和知识记录。
- 客户用户只能看到授权租户、组织、站点和对象。
- 状态、来源和更新时间应清晰可见。
- 保持统一交互、错误提示和加载状态。
